## R1 冬季の暫定検証 (Historical Forecast API; 短いリードのみ)
予報: Historical Forecast API (最新の予報の継ぎ足し、lead 指定不可) の気圧面 → 本体と同じ山頂内挿、value_h1 (T-1h/T 平均)。
実況: 麓の sun1h >= 0.4h (etrn_cache 優先)。地点: karamatsu/白馬, akadake/野辺山, nikko_shirane/奥日光。
R1 = d1-2 行 (lead 0-48h) の P(晴れ)。生値 = 1 − 雲量/100。d_brier = Brier(R1) − Brier(生値) (負 = R1 が良い)。
95% 区間と p_boot_r1_better は日単位ブロックのブートストラップ (2000 回, seed 20260923)。
summer は R1 の学習と同じ期間・同じ実況 (表にとって標本内) なので、冬との比較の対照 (上限側) として読む。
