# R12 の修正案の検証 — MSM の d1-2 行を 7 面の山頂雲量で学習し直す

作成 2026-09-23。本体は変更しない。数表は [r12-msm-retrain-tables.txt](r12-msm-retrain-tables.txt)
(`python -m backtest.r12_msm_retrain fetch` → `eval` → `export`)。新しい表は [mos_tables/r1-summit-cloud-sunny-msm7.json](../mos_tables/r1-summit-cloud-sunny-msm7.json)
(既存の `r1-summit-cloud-sunny.json` は変更していない)。

> **結論の範囲**: 学び直したのは **MSM の d1-2 行 (lead 0〜48h) だけ**。学習と評価に使った Historical Forecast API は短いリードを継ぎ足した系列で、
> 結論は短いリードについてのもの。**MSM の d3-4 行は 5 面学習のまま** (旧表をそのまま複写)、**ECMWF の行は変えていない**。

## 1. 方法

| 項目 | 内容 |
|---|---|
| 予報 | Historical Forecast API の jma_msm、1000〜600hPa の 7 面、麓 4 地点 (唐松岳/白馬、赤岳/野辺山、日光白根山/奥日光、安達太良山/鷲倉)。生 JSON は `data/raw/historical_forecast_r12/` |
| 標本 | R1 の学習と同じ (地点, valid_time) の組 (`trackb_eval.lead_day_pairs` の jma_msm、富士山除外、日中 07〜17 時; リードが違っても同じ時刻は 1 組)。Historical の値がある 3,344 時間・99 日 |
| 山頂雲量 | 本体と同じ内挿 (`summit_interp`)。**7 面** (本体の Forecast API と同じ) と **5 面** (900/800 を除く = R1 学習時の Single Runs と同じ) の 2 通り。予報値は value_h1 (T−1h/T 平均) |
| 表の作り方 | 学習コード (`cloud_calibration_table.build`) と同じ: 同じ 8 ビン、ビンごとの晴れ率、n 重み付き PAV |
| 比べた表 | **旧表** (Single Runs・5 面、R1 v1.5.0)、**Historical・5 面**、**Historical・7 面** (= 新表の d1-2 行) |
| 評価 | Historical の 2 表は **地点を 1 つずつ外して学習** (leave-one-site-out) し、外した地点で評価。Brier、AUC、信頼度。差の 95% 区間は日単位ブロックのブートストラップ (2,000 回、seed 20260923、日の並びは固定) |

組み合わせ (いずれも MSM の d1-2 行):

- **A** = 旧表を 7 面の入力に当てる (**今の本体**)
- **B** = Historical・7 面表を 7 面の入力に (**提案**)
- **C** = 旧表を 5 面の入力に (学習と同じ入力)
- **D** = Historical・5 面表を 5 面の入力に

B − A = 提案の効果、D − C = **データ源の違い** (面は同じ 5 面)、B − D = **面の数の違い** (データ源は同じ Historical)。

## 2. 結果

### 2.1 Brier と差

| 案 | Brier | AUC |
|---|---|---|
| A 旧表 × 7 面 (今の本体) | 0.1863 | 0.804 |
| B Historical 7 面表 × 7 面 (提案) | **0.1756** | 0.797 |
| C 旧表 × 5 面 (学習と同じ) | 0.1750 | 0.801 |
| D Historical 5 面表 × 5 面 | 0.1774 | 0.791 |
| 生値 1 − 雲量/100 (7 面 / 5 面) | 0.2846 / 0.3381 | 0.808 / 0.807 |
| 気候値 | 0.2373 | — |

| 差 | ΔBrier [95% 区間] | 前の方が良い割合 |
|---|---|---|
| **提案の効果 B − A** | **−0.0107 [−0.0206, −0.0009]** | 0.98 |
| データ源の違い D − C | +0.0024 [−0.0007, +0.0056] | 0.06 |
| 面の数の違い B − D | −0.0018 [−0.0084, +0.0054] | 0.72 |

- **提案は今の本体より有意に良い** (区間が 0 をまたがない)。B (0.1756) は、旧表に学習と同じ 5 面の入力を与えた C (0.1750) とほぼ同じ。
  つまり「旧表に 7 面の入力を与えている」ことによる損 (A − C = +0.0113) を、ほぼそのまま取り戻している。
- 地点を外したときの提案の効果 (外した地点での ΔBrier): 赤岳 −0.014、唐松岳 −0.018、日光白根山 −0.002、安達太良山 +0.006 (8 日・88 時間しか無い)。
- **AUC は判断に使えない**: 表は入力のビンについて単調なので、1 つの表の中では AUC は入力のビンだけで決まる。ここでの AUC の差は、地点を外すごとに表の値が
  少しずつ違うこと (異なる表の予報を混ぜた順位) から来ている。入力そのものの順序付けは 7 面 0.808 と 5 面 0.807 で同じで、**R12 は判別の問題ではなく較正 (確率の水準) の問題**。

### 2.2 信頼度 (入力のビンごと)

今の本体 (A) は 7 面の入力に対して晴れの確率を一貫して低く見積もっている: 0% ビンで P=0.719 に対し実況 0.822、(0,10] で 0.511 に対し 0.687、
(10,20] で 0.362 に対し 0.517、(20,30] で 0.247 に対し 0.342。提案 (B) はそれぞれ 0.817 / 0.676 / 0.510 / 0.340 で実況に合う。
C・D (5 面の入力) は旧表・Historical 表とも実況に近い。

### 2.3 新しい d1-2 行と基準値 (P_ref)

| ビン | 旧表 P | Historical 5 面 P | **新表 P (Historical 7 面)** | 実効雲量 v1.5.0 (d1-2) | **実効雲量 新表 (d1-2)** | d3-4 行の実効雲量 (旧基準値 = v1.5.0 と同じ) |
|---|---|---|---|---|---|---|
| 0 | 0.719 | 0.807 | 0.822 | 0.0 | 0.0 | 18.6 |
| (0,10] | 0.511 | 0.558 | 0.687 | 28.9 | 16.4 | 36.9 |
| (10,20] | 0.362 | 0.359 | 0.517 | 49.7 | 37.1 | 47.6 |
| (20,30] | 0.247 | 0.241 | 0.342 | 65.6 | 58.4 | 63.3 |
| (30,40] | 0.149 | 0.177 | 0.260 | 79.3 | 68.4 | 66.9 |
| (40,50] | 0.118 | 0.120 | 0.142 | 83.6 | 82.7 | 79.7 |
| (50,70] | 0.073 | 0.052 | 0.062 | 89.8 | 92.5 | 82.9 |
| (70,100] | 0.071 | 0.050 | 0.041 | 90.1 | 95.0 | 94.4 |

- **基準値 P_ref (MSM の d1-2 行の 0% ビン): 旧 0.719 → 新 0.822 (+0.103)**。新表では d1-2 行は新しい基準値で、d3-4 行は旧基準値 0.719 で正規化している
  (各行の `normalization` に明記)。d3-4 行と ECMWF の全行の実効値が本体 v1.5.0 と完全に一致することは `tests/test_mos_equivalence.py` で確認した
  (本体 52d3d2a と、型まで含めて == で比較)。
- 仮に d3-4 行も新基準値で正規化すると、実効雲量は 0% で 18.6 → 28.8、(0,10] で 36.9 → 44.8 とビンにより 0.7〜10.2 ポイント辛くなる (採用していない)。
- **ビンごとの変化の出どころ**:
  - 0% ビンの上昇 (0.719 → 0.822) のうち **+0.088 はデータ源の違い** (旧表 0.719 → Historical 5 面 0.807)、面の数の違いは +0.015 (0.807 → 0.822) だけ。
    つまり **基準値の上昇の大半は、Historical の短いリードの性質によるもので、R12 (900/800) の修正によるものではない**。
  - 面の数の違いが効くのは 0〜40% のビン (Historical 5 面 → 7 面: (0,10] 0.558 → 0.687、(10,20] 0.359 → 0.517、(20,30] 0.241 → 0.342、(30,40] 0.177 → 0.260)。
    7 面では 800hPa の湿りを拾って同じ天気でも雲量が高めに出る (R12) ので、同じビンの晴れ率が上がる。R12 の影響の向きと合う。

## 3. 注意点

1. **データ源の違い (リードの性質) が混ざる**。旧表は Single Runs の 00Z ランで lead 0〜48h を明示的に束ねた行、新表の d1-2 行は Historical の「最新予報の継ぎ足し」
   (実質のリードは短く、指定できない) で学習した。短いリードほど「晴れ予報のときに本当に晴れる」割合が上がるので、新表の晴れ側 (0%・(0,10]) の P は、
   本当の lead 0〜48h (特に 2 日目) より高めに出ている可能性が高い。上の切り分けでは、**0% ビンの差の大半 (+0.088 / +0.103) がこの成分**。
   - 評価も Historical で行ったので、B の成績にはこの「データ源が評価データと同じ」有利さが混ざりうる。ただし 5 面同士ではデータ源の違いは有意でなく
     (D − C = +0.0024、旧表の方がわずかに良い)、B − A の改善 (−0.0107) は A − C の損 (+0.0113) とほぼ同じ大きさなので、改善の主な中身は面の数の不一致の解消と読める。
   - 旧表はこの評価の実況 (同じ期間・同じ地点の日照) で学習済み (標本内)、Historical の表は地点を外して評価 (標本外)。この点は旧表側に有利。
2. **リードの継ぎ目の段差が大きくなる**。案C では d1-2 行の 0% が実効 0%、d3-4 行の 0% が 18.6%。(0,10] のビンでは 2 日目 → 3 日目の実効雲量の段差が
   v1.5.0 の +8.0 (28.9 → 36.9) から新表では +20.5 (16.4 → 36.9) に広がる。曇りのビン ((30,40] 以上) では d3-4 行の方が d1-2 行より甘い (v1.5.0 と同じ性質:
   遠いリードほど曇り予報の確率が気候値に寄る)。
3. **MSM の d3-4 行は 5 面学習のまま** (新表のメタデータ `status` に「5 面で学習、未更新」)。本体で MSM の d3-4 行が引かれるのは、Forecast API のスナップショット
   21 件で数えると **1 回の予報あたり 16〜40 時間 (平均 28.6 時間)、うち日中 07〜17 時は 9〜20 時間 (平均 13.1 時間)**: 取得日から数えて 3 日目 (16〜24 時間) と
   4 日目の 03 時または 15 時まで (0〜16 時間)。18 時台 (JST) の取得で最大 40 時間。**この時間帯は R12 の入力の不一致が残る**。2027 年 3 月に
   Forecast スナップショット (7 面・リード付き) で作り直す ([r1-winter-provisional.md](r1-winter-provisional.md) §4 の手順 5)。
4. **ECMWF の行は変えていない** (ECMWF は学習・本体とも 900/800 が null で、R12 の影響を受けない)。
5. 暖候期・日中だけ (新表の d1-2 行も `hours_jst` 7〜17、`months` 6〜9)。安達太良山は 8 日で provisional (他 3 地点は 99 日で confirmed)。

## 4. 結論と次の判断

- 短いリードの MSM d1-2 行について、**7 面で学び直した表は、今の本体 (旧表に 7 面を与えている状態) より Brier が有意に良い** (−0.0107 [−0.0206, −0.0009])。
  主な中身は「旧表が 7 面の入力に対して晴れを低く見積もる」ことの解消で、判別力 (AUC) は変わらない。
- ただし新しい行の晴れ側の確率には、Historical の短いリードの性質が大きく混ざっている (0% ビンの差の大半)。**このまま本体に入れると、2 日目の晴れ予報を
  やや甘く扱う可能性がある**。
- 本体に入れるかどうかの選択肢 (判断は本体側):
  1. 新表をそのまま使う (d1-2 は Historical・7 面、d3-4 は旧表のまま)。上の注意 1・2 を既知の制約として明記する。
  2. 面の数の効果だけを旧表に移す: 旧表の d1-2 行に、ビンごとの比 (Historical 7 面 / Historical 5 面) を掛ける。データ源の違いを打ち消す狙いだが、
     比が lead に依存しないという仮定を置く (未評価。参考値: 0.732 / 0.629 / 0.521 / 0.351 / 0.219 / 0.140 / 0.087 / 0.058、基準値 0.732)。
  3. 2027 年 3 月の Forecast スナップショット (7 面・リード付き) で d1-2 と d3-4 の両方を作り直すまで待つ。
