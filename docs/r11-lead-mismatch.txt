## R11 lead の数え方の違いで本体が学習時と違う行を引く割合
入力: data/parquet/single_runs_long.parquet の cloud_cover_at_summit (00Z ラン 2026-06-12〜09-17) の (model, run, valid_time)。
run = 本体が使ったと仮定するランの初期時刻 (00Z 以外は 00Z の valid_time の組を流用した仮想ラン)。
today = 本体の取得日 (JST) がランの初期時刻の JST 日付と同じ (+0) / 翌日 (+1)。本体の系列は today 00 時 JST から。
lead_day_differs = 本体 lead_day ≠ 学習 lead_day の割合、row_differs = 引く行 (lead 群) が違う割合。
